# 📅 Events Manager

A simple and responsive **Events Manager** built with **HTML, CSS, and Vanilla JavaScript**.

The app allows users to create events, save them locally, track their countdown in real time, and delete events when needed.

## ✨ Features

- ➕ Add new events
- 🗑️ Delete events
- ⏳ Real-time countdown
- 💾 Persistent data using `localStorage`
- 📅 Prevent selecting past dates
- 🔄 Automatic countdown updates
- 📱 Responsive layout

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🧠 Concepts Practiced

- DOM Manipulation
- Event Handling
- Objects & Arrays
- Local Storage
- JSON
- Date & Timestamps
- `setInterval()`
- Template Literals
- Dynamic DOM Updates
